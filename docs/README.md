# Stackr Documentation

This directory contains documentation for the stackr project.

## Documentation Structure

- `digi-infra/` - Symlink to digi-infrastructure documentation (always up-to-date)
- `pcs/` - Symlink to PCS (Prompt and Context Service) documentation
- `CI_CD_STRATEGY.md` - Local stackr CI/CD documentation
- `recipes/` - Local stackr specific recipes and guides

## Notes

- Symlinks automatically reflect the latest content from digi-infrastructure
